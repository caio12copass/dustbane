# [DUSTBANE]

<p align="center">
  <strong>Explore. Aspire. Evolua. Enfrente a poeira. :)</strong>
</p>

**Dustbane** é um jogo indie de ação e exploração com elementos de roguelite, desenvolvido em HTML, CSS e JavaScript.

Em um mundo dominado por criaturas de poeira, sua principal ferramenta de sobrevivência é um aspirador. Explore ambientes perigosos, enfrente criaturas, colete recursos e avance cada vez mais fundo nessa aventura.

## [GAME] Sobre o jogo

Dustbane mistura exploração, combate e progressão em uma experiência que combina uma área central com expedições por regiões perigosas.

Entre uma aventura e outra, o jogador pode retornar à vila, se preparar e continuar sua jornada.

## [FEATURES] Principais características

- **Combate com aspirador:** utilize diferentes funções do equipamento para lidar com os inimigos.
- **Exploração:** descubra áreas, salas, caminhos alternativos e passagens secretas.
- **Progressão:** colete recursos e aprimore suas possibilidades durante a aventura.
- **Chefes:** enfrente criaturas únicas, com aparências e padrões de ataque próprios.
- **Vila:** utilize a área central como ponto de apoio entre as expedições.
- **Elementos roguelite:** encare desafios e descubra novas possibilidades a cada exploração.

## [TECH] Tecnologias

O projeto é desenvolvido utilizando tecnologias web:

- HTML5
- CSS3
- JavaScript

Sem necessidade de uma engine tradicional: o jogo utiliza tecnologias do navegador para funcionar.

## [IN DEVELOPMENT] Desenvolvimento

Dustbane é um projeto independente em desenvolvimento. Novas mecânicas, melhorias visuais, regiões, inimigos e conteúdos estão sendo trabalhados ao longo do projeto.

O objetivo é construir uma experiência cada vez mais completa, com identidade visual própria e sistemas de jogo bem integrados.
